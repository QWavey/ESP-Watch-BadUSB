💀 DeadNet — WIRED LAN attack

                    

                        ARP-poison / DEAUTH / DNS-spoof every host on the wired LAN the watch is attached to via a USB-C Ethernet adapter (same idea as flashnuke's deadnet_lan_kill against eth1). The AP that hosts this dashboard stays up on WiFi. 


                        Availability: the USB-Host + Ethernet-adapter driver is not yet implemented — plugging a USB-C-to-Ethernet adapter into the watch does NOT bring up an eth netif today. Switch stays disabled until the driver lands.
